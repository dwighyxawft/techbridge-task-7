Your 30-day journey, one task at a time

TechBridge provides a structured 30-day practical internship. You progressively develop your web development skills by completing practical projects, and each task is a step up from the one before.

All 8 tasks, in order

Open any task to see what you are expected to build.

  1. 1

    Day1

    Available

    Beginner

    Task 1

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    What you'll build

    You'll be expected to create:

    • A homepage that introduces TechBridge, its programs and its 30-day internship
    • Clear navigation, a community call-to-action, contact details and a footer
    • A layout that works on desktop, tablet and mobile
  2. 2

    Day4

    Available

    Beginner

    Task 2

    Build the TechBridge Programs Experience

    Create a Programs experience presenting TechBridge's available learning programs.

    What you'll build

    You'll be expected to create:

    • A dedicated Programs page or experience for Data Analytics and Web Development
    • Clear information on what each program is about and the skills it develops
    • A clear next step for visitors

    Connects to: The website you built in Task 1.

  3. 3

    Day8

    Available

    Beginner → Intermediate

    Task 3

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    What you'll build

    You'll be expected to create:

    • An introduction to the structured 30-day internship
    • All 8 tasks, each with its number, title, day and a brief description
    • A clear sense of the sequence and the increasing difficulty
    • Built with HTML5 and CSS3, and responsive on desktop, tablet and mobile

    Connects to: The Home and Programs pages from Tasks 1 and 2.

  4. 4

    Day11

    Available

    Beginner → Intermediate

    Task 4

    Build an Interactive Internship Roadmap

    Use JavaScript to allow visitors to switch between the Data Analytics and Web Development internship tracks.

    What you'll build

    You'll be expected to create:

    • A way for visitors to select the Data Analytics or Web Development track
    • Task content that switches between the two tracks without a page refresh
    • Built with HTML5, CSS3 and JavaScript, with no frameworks

    Connects to: The task experience from Task 3.

  5. 5

    Day15

    Available

    Beginner → Intermediate

    Task 5

    Build the TechBridge Challenge Hub

    Create an interactive Challenge Hub where visitors can browse, filter and explore challenges from the two TechBridge tracks.

    What you'll build

    You'll be expected to create:

    • A Challenge Hub page where visitors can browse challenges from both tracks
    • Filters for track and difficulty
    • Challenge details that appear without a page refresh

    Connects to: The Home, Programs and roadmap pages from earlier tasks.

  6. 6

    Day19

    Available

    Intermediate

    Task 6

    Build the TechBridge Intern Dashboard

    Create an interactive intern dashboard where an intern can see their progress, track their tasks and explore the Challenge Hub.

    What you'll build

    You'll be expected to create:

    • A welcome section, plus a progress bar and percentage that update as tasks are completed
    • A task tracker with filters and task details
    • A link to the Challenge Hub and a Modern Web Technologies explorer

    Connects to: The Challenge Hub from Task 5.

  7. 7

    Day22

    Upcoming

    Intermediate

    Task 7

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    What you'll build

    You'll be expected to create:

    • An interface where interns can prepare their task work
    • A way for interns to submit that work
  8. 8

    Day26

    Upcoming

    Intermediate

    Task 8

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    What you'll build

    You'll be expected to create:

    • The components from the earlier tasks, combined
    • A complete TechBridge internship platform

    Connects to: The components created across the internship.
