      The API endpoints used by the dashboard
      MethodEndpointWhat it doesUsed for
      GET/api/tasksReturns all 8 tasks as JSONDrawing the task cards and progress
      GET/api/tasks/:idReturns one task, for example /api/tasks/3The View Task dialog
      PUT/api/tasks/:idUpdates a task's status. Body: { "status": "completed" }Mark as Completed and Undo
      GET/api/healthSays whether the backend is runningThe Backend Status light
      POST/api/resetPuts every task back to its starting statusThe Reset progress button
